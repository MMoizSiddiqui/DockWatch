# Third-party notices

DockWatch is distributed as a packaged program that contains the open-source components below,
each under its own licence. DockWatch's own licence ([LICENSE](LICENSE)) does not change their
terms. **The full licence texts are included in the download**, in `THIRD_PARTY_LICENSES.txt`
next to the DockWatch engine (`engine/THIRD_PARTY_LICENSES.txt` in the Windows download).

**Downloaded at run time, not included in the package:** the scanners
[Hadolint](https://github.com/hadolint/hadolint) (GPL-3.0),
[Trivy](https://github.com/aquasecurity/trivy) (Apache-2.0) and
[Dockle](https://github.com/goodwithtech/dockle) (Apache-2.0) are downloaded from their official
releases on your computer and run as separate programs. On Windows, Dockle runs from its
official Docker image `goodwithtech/dockle`.

**Packaging:** built with [PyInstaller](https://pyinstaller.org) (GPL-2.0 with the PyInstaller
bootloader exception, which allows distributing programs built with it under any licence).
